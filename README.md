# Plataforma de Turismo em Foz do Iguaçu

Projeto desenvolvido para a disciplina de **Projeto Integrador de Extensão II** do curso de **Engenharia de Software**.

## Sobre o projeto

Desenvolvimento de uma aplicação web para uma empresa real do setor de turismo de Foz do Iguaçu - PR.

A plataforma tem como objetivo apresentar os passeios e pacotes turísticos oferecidos pela empresa e facilitar o processo de solicitação de reservas por meio do WhatsApp.

## Funcionalidades previstas

- Visualização dos passeios disponíveis;
- Visualização dos detalhes de cada passeio;
- Informações sobre a quantidade mínima e máxima de passageiros;
- Seleção da data de início do passeio;
- Seleção da data de saída;
- Seleção da quantidade de pessoas;
- Resumo da solicitação;
- Redirecionamento para o WhatsApp da empresa;
- Geração de mensagem automática com os dados da solicitação;
- Visualização de pacotes e roteiros turísticos.
